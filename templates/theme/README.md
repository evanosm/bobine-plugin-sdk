# {{name}}

A theme for [Bobine](https://genez.app/bobine), made with `@bobine/plugin-sdk`.

```sh
npx --package=@bobine/plugin-sdk bobine-plugin check   # bobine.json and files, with Bobine's rules
npx --package=@bobine/plugin-sdk bobine-plugin pack    # writes {{id}}-0.1.0.bobine-ext
npx --package=@bobine/plugin-sdk bobine-plugin login   # once: your Bobine account
npx --package=@bobine/plugin-sdk bobine-plugin publish # public and final for this version
```

In Bobine: Plugins > Load an extension in development…, then choose this folder.
